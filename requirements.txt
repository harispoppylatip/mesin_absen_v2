# Kebutuhan layanan wajah InsightFace untuk aplikasi absen solat.
#
# CARA PASANG, DUA LANGKAH DAN URUTANNYA PENTING
# ----------------------------------------------
#     python -m venv .venv
#     .\.venv\Scripts\python.exe -m pip install -r requirements.txt
#     .\.venv\Scripts\python.exe tambal_insightface.py      <-- WAJIB
#
# Berkas ini SENGAJA TIDAK memuat insightface.
#
# `pip install insightface==0.7.3` selalu mengunduh berkas SUMBER, bukan roda
# siap pakai, lalu mencoba mengompilasi satu ekstensi C++ bernama
# `mesh_core_cython`. Ekstensi itu hanya dipakai untuk render topeng wajah 3D,
# sedangkan deteksi dan pengenalan wajah tidak memakainya sama sekali. Karena
# itu pemasangan gagal di DUA tempat sekaligus:
#
#   Windows tanpa Windows 10 SDK
#       fatal error C1083: Cannot open include file: 'stdio.h'
#   python:3.10-slim di dalam Docker, yang memang tidak membawa compiler
#       error: [Errno 2] No such file or directory: 'g++'
#       ERROR: Failed building wheel for insightface
#
# Langkah KEDUA menempuh jalan lain: mematikan ekstensi itu, memasang pengganti
# murni Python, lalu memasang paketnya dengan `--no-build-isolation --no-deps`.
# Cara itu terbukti bekerja di Windows dan dipakai juga oleh Dockerfile, jadi
# tidak ada DUA salinan logika tambalan yang harus diubah bersamaan.
#
# Di Linux dan di dalam Docker, berkas yang sama dipakai apa adanya: baris
# opencv memakai penanda lingkungan, jadi Windows mendapat opencv yang bisa
# membuka jendela sedangkan Linux mendapat versi tanpa tampilan supaya tidak
# perlu memasang pustaka grafik di dalam citra.

# --- perkakas bangun --------------------------------------------------
# Dipakai langkah KEDUA. insightface dipasang dengan --no-build-isolation,
# artinya pip TIDAK menyiapkan perkakas bangunnya sendiri, sehingga seluruh isi
# [build-system] pada pyproject.toml insightface (setuptools, numpy, cython)
# wajib sudah ada di sini.
#
# Perhatikan juga: setup.py insightface mengimpor Cython dan numpy di baris
# paling atas, jadi keduanya tetap WAJIB ada walau ekstensi C++-nya dimatikan.
#
# Versi setuptools di bawah bukan tebakan, itu versi yang benar benar dipakai
# saat pemasangan di Windows berhasil.
setuptools==84.0.0
wheel==0.48.0
Cython==3.0.12
numpy==1.26.4

# --- angka dan gambar -------------------------------------------------
Pillow==12.3.0
opencv-python-headless==4.11.0.86 ; sys_platform != "win32"

# matplotlib BUKAN hiasan dan BUKAN pilihan.
#
# Rantai impornya begini: `insightface.app` mengimpor `mask_renderer`, yang
# mengimpor `thirdparty.face3d`, yang mengimpor `mesh`, dan `mesh/__init__.py`
# menulis `from . import vis`, sedangkan `vis.py` memakai matplotlib. Jadi
# `import insightface` GAGAL tanpa matplotlib, walau deteksi dan pengenalan
# wajah sendiri tidak menyentuhnya.
#
# Daftar ini diperiksa dengan mengamati modul yang benar benar termuat saat
# mengimpor insightface.app, bukan hanya dipercaya dari install_requires
# paketnya. Cara itu penting karena insightface dipasang memakai --no-deps:
# setiap kebutuhan yang tidak tertulis di berkas ini TIDAK akan ikut terpasang,
# dan kegagalannya baru muncul sebagai ModuleNotFoundError saat layanan dipakai.
matplotlib==3.10.9
