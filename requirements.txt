# Kebutuhan layanan wajah InsightFace untuk aplikasi absen solat.
#
# Pemasangan di Windows:
#     python -m venv .venv
#     .\.venv\Scripts\python.exe -m pip install -r requirements.txt
#
# Di Linux dan di dalam Docker, berkas yang sama dipakai apa adanya: baris
# opencv memakai penanda lingkungan, jadi Windows mendapat opencv yang bisa
# membuka jendela sedangkan Linux mendapat versi tanpa tampilan supaya tidak
# perlu memasang pustaka grafik di dalam citra.
#
# Catatan tentang insightface 0.7.3
# ---------------------------------
# Paketnya hanya tersedia sebagai kode sumber. Di Windows, berkas setup.py-nya
# memaksa kompilasi modul Cython `mesh_core_cython` yang hanya dipakai untuk
# render wajah 3D, dan kompilasi itu gagal tanpa Visual Studio Build Tools.
# Skrip `install-insightface.ps1` di folder induk mengurus itu: mengosongkan
# `ext_modules`, menambahkan pengganti murni Python untuk mesh_core_cython,
# lalu memasangnya dengan `--no-build-isolation`. Modul itu tidak pernah
# dipanggil oleh deteksi maupun pengenalan wajah.
#
# Di dalam Docker pemasangan berjalan normal tanpa skrip itu, karena dasar
# citranya sudah memuat perkakas bangun (lihat Dockerfile).
